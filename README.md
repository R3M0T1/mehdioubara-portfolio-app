# Mehdi Oubara — Portfolio

Recruiter-facing Next.js portfolio built with [1st-Pouf](https://1st-pouf.worksonmy.dev/) (pastel claymorphism UI).

## Features

- Locales: English, Français, Español, Português, Deutsch, Nederlands (`/en`, `/fr`, …)
- Role focus filter: Back-End / Web3 / Full stack / DevOps
- CV-based experience, projects (media placeholders), skills, education
- Contact / Hire form (opens mailto with engagement + focus)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000/en](http://localhost:3000/en).

## Stack

- Next.js 16 (App Router) + React 19
- Tailwind CSS v4 + 1st-Pouf components (owned source under `src/components/pouf`)
- next-intl
