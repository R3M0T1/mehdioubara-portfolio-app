# Portfolio plan

## Goal
Recruiter-facing Next.js portfolio for Mehdi Oubara using 1st-Pouf UI, 6 locales, role filters, project placeholders, Contact/Hire CTA.

## Stack
- Next.js (App Router) + React 19
- Tailwind CSS v4 + 1st-Pouf (shadcn registry)
- next-intl (en, fr, es, pt, de, nl)
- Framer Motion (via Pouf components)

## Vertical slices
1. Scaffold + Pouf theme + landing shell
2. Content model + translations from CV
3. Hero, nav, language switcher, role filter
4. Experience / skills / projects / education sections
5. Contact form + polish + build verify

## Out of scope
Blog, CMS, real project media, email backend, auth
